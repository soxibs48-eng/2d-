# PIXEL RUNNER: BOSHQARUV QO‘LLANMASI (CONTROLS GUIDE)

Ushbu hujjat "Pixel Runner" o‘yini uchun barcha platformalardagi boshqaruv tizimini to‘liq tavsiflaydi.

---

## 1. Klaviatura (PC / Web)

| Tugma | Funksiya | Izoh |
| :--- | :--- | :--- |
| `Space` / `W` / `Up Arrow` | **Sakrash (Jump)** | Poldan yuqoriga yoki shiftda yurganda pastga sakraydi. |
| `S` / `Down Arrow` | **Egilish (Slide)** | Polda yoki shiftda egiladi (kolliziya balandligi 2 barobar qisqaradi). |
| `S` / `Down Arrow` (Havoda) | **Tez Tushish (Fast Fall)** | Havoda bo‘lganda tayanch yuzasiga tezroq tortiladi. |
| `Shift` / `F` | **Antigravitatsiya (Flip)** | **Gravity Core** quvvati faol bo‘lganda gravitatsiyani almashtiradi. |
| `Escape` / `P` | **Pauza (Pause)** | O‘yinni to‘xtatib turish yoki davom ettirish. |

---

## 2. Gamepad / Controller (Xbox / PlayStation / Generic)

| Gamepad Tugmasi | Standart Funksiya |
| :--- | :--- |
| **A / Cross (Button 0)** | Sakrash (Jump) |
| **B / Circle (Button 1)** | Egilish (Slide) |
| **X / Square (Button 2)** | Antigravitatsiya Flip |
| **Y / Triangle (Button 3)** | Antigravitatsiya Flip |
| **D-Pad Up** | Sakrash |
| **D-Pad Down** | Egilish |
| **Start / Options (Button 6)** | Pauza menyusi |

---

## 3. Sensorli Ekran / Mobil (Android / WebGL Mobile)

| UI Elementi | Joylashuvi | Funksiya |
| :--- | :--- | :--- |
| **JUMP** tugmasi | O‘ng pastki burchak (yuqoriroq) | Sakrash |
| **SLIDE** tugmasi | O‘ng pastki burchak (pastda) | Egilish / Sirpanish |
| **FLIP GRAVITY** tugmasi | Chap pastki burchak | Gravitatsiyani 180° ga aylantirish (Gravity Core faolligida ko‘rinadi) |
| **II (Pause)** tugmasi | O‘ng yuqori burchak | Pauza menyusi |
